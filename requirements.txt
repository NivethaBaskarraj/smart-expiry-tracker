# Smart Expiry Tracker — Project Stack & System Requirements

> **Note**: This is a full-stack JavaScript application (Node.js/Express + React 18).
> Dependencies are strictly managed via `package.json` in the root, `server/`, and `client/` directories.
> To install all dependencies, run:
> ```bash
> npm run install:all
> ```

---

## 1. System Requirements

| Requirement | Supported Version | Notes |
|---|---|---|
| **Node.js** | v18.x or later (v20+ recommended) | Tested on Node v22 |
| **npm** | v9.x or later | Bundled with Node.js |
| **Database** | MongoDB Atlas (Cloud) or MongoDB v6+ (Local) | Connection URI in `server/.env` |
| **Operating System** | Windows (PowerShell/CMD), macOS, Linux | Cross-platform scripts |
| **Browser** | Chrome, Edge, Firefox, Safari | Modern web browser with Notifications API |

---

## 2. External Services Supported

| Service | Purpose | Free Tier Available? |
|---|---|---|
| **MongoDB Atlas** | Database storage | Yes (Free Shared M0 cluster) |
| **Brevo (HTTP API)** | Email alerts & password resets (Recommended for Render) | Yes (300 emails/day free) |
| **Resend (HTTP API)** | Email alerts alternative | Yes (100 emails/day free) |
| **Gmail (SMTP)** | Standard SMTP via Nodemailer | Yes (Gmail App Password) |
| **Spoonacular Food API** | Recipe suggestions by ingredient | Yes (150 requests/day free) |
| **Twilio (Optional)** | SMS expiry alerts (Feature-flagged behind `ENABLE_SMS_ALERTS`) | Trial available |
| **cron-job.org / Webhook** | External pinger for waking Render and running daily cron | Free |
